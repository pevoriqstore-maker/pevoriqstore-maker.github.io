O que é

JARVIS Private Backup é uma integração privada, instalada no computador do proprietário, que utiliza o rclone e a API do Google Drive para armazenar cópias criptografadas de arquivos selecionados de recuperação do projeto JARVIS.

Como funciona

O proprietário autoriza sua própria conta Google. A integração solicita somente a permissão drive.file, adequada para trabalhar com arquivos criados ou disponibilizados ao aplicativo. Os dados de backup são criptografados localmente antes do envio ao Google Drive. As credenciais OAuth permanecem no computador do proprietário.

O aplicativo não é oferecido ao público, não aceita inscrições e não concede acesso remoto ao computador por meio deste site. Esta página é apenas informativa.

Leia a Política de privacidade e os Termos de uso.
